🧠 What Is Normalization?
Normalization is the process of organizing data in a relational database to reduce duplication and ensure logical data storage. It’s like designing a hospital where each department knows exactly what it’s responsible for—no confusion, no overlap.

🎯 Why We Normalize
- To avoid storing the same information in multiple places
- To make updates easier and safer
- To ensure each piece of data lives in the right place
- To improve query performance and data integrity
 

📚 Types of Normal Forms (NF)
Here’s how normalization progresses:
- 1NF: Ensures each record is unique and all values are atomic (no lists or groups)
- 2NF: Ensures every non-identifier detail depends fully on the identifier
- 3NF: Ensures no indirect dependencies between details
- BCNF and beyond: Handle more advanced relationships and constraints



SELECT *FROM hospital.patient;

CREATE TABLE hospital.patient(
	pati_id SERIAL PRIMARY KEY,
	pati_name VARCHAR NOT NULL,
	pati_age INT CHECK (pati_age>0) NOT NULL,
	disease VARCHAR NOT NULL,
	doc_id INT NOT NULL,
	medi_id INT NOT NULL,
	room_no INT NOT NULL UNIQUE,
	FOREIGN KEY (doc_id) REFERENCES hospital.doctor(doc_id),
	FOREIGN KEY (medi_id) REFERENCES hospital.medicine(medi_id),
	FOREIGN KEY (room_no) REFERENCES hospital.room(room_no)
);
