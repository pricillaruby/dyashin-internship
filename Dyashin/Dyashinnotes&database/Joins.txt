JOINS :

A join is a way to get data from two tables and show it together. You use it when one table has part of the info, and another table has the rest.

🧩 Types of Joins :
- INNER JOIN: Shows only the matching rows from both tables.
- LEFT JOIN: Shows all rows from the first table, and matches from the second.
- RIGHT JOIN: Shows all rows from the second table, and matches from the first.
- FULL JOIN: Shows everything from both tables, even if there’s no match.
- CROSS JOIN: Combines every row from one table with every row from the other.
- SELF JOIN: Joins a table to itself (like comparing rows inside the same table).

SELECT e.employee_id,e.employee_name,d.dept_name
FROM newcompany.Employees e
INNER JOIN newcompany.department d
on e.dept_id = d.dept_id

SELECT e.employee_id,e.employee_name,d.dept_name
FROM newcompany.Employees e
LEFT JOIN newcompany.department d
on e.dept_id = d.dept_id

SELECT e.employee_id,e.employee_name,d.dept_name
FROM newcompany.Employees e
RIGHT JOIN newcompany.department d
on e.dept_id = d.dept_id

SELECT e.employee_id,e.employee_name,d.dept_name
FROM newcompany.Employees e
FULL OUTER JOIN newcompany.department d
on e.dept_id = d.dept_id

SELECT e.employee_id,e.employee_name,d.dept_name
FROM newcompany.Employees e
CROSS JOIN newcompany.department d
